# Akio Edits

Arabic portfolio website for professional video editing services ("عالم المونتاج الاحترافي"). A single-page dark-themed site with neon glow styling, Google Fonts (Cairo, Orbitron) and Font Awesome icons.

## Files
- `akio/index.html` - the site
- `akio/videos/` - video assets

Open `akio/index.html` in a browser to view it.
